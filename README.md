# clnuke-power
Sistema de CL (clear-dm) + nuke discord

## Instalação

Clone o repositório:

```bash
git clone https://github.com/onlinemaxxing/clnuke-power.git
cd clnuke-power
```

Instale as dependências:

```bash
pip install -r requirements.txt
```

Execute:

```bash
python main.py
```

Dependências
aiohttp
requests
colorama
